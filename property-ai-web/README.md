# property-ai-web

Nuxt 4 + Nuxt UI + Pinia frontend for the Property AI project. See the [root README](../README.md)
for setup, environment variables, and how this fits together with `property-ai-api-nest`.

## Common commands

```bash
pnpm run dev         # dev server
pnpm run typecheck   # vue-tsc
pnpm run lint         # eslint
```
